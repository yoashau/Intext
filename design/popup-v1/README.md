# 浮层 v1

2026-11-02 锁定。这是划词弹出的界面参照，不是整份软件规格。

以后做界面时打开 `popup.html`，按它的层次、留白、字重和符号来，不要另起一套工具窗。纸面和选区没有入选。

## 锁定

- 划词结果是一块独立浮层，贴在选中文字附近，不占满窗口，也没有标题栏。
- 译文是主体。原文更小、更淡，放在译文下面。
- 语言名、缓存状态、模型名用文字。只有对调、再译、复制、固定用符号。
- 缓存写成「已缓存」或「未缓存」，不是色块徽章。
- 模型名只显示名称，例如 `gpt 6.1 sol`。浮层里不出现温度、思考强度或其他请求参数。
- 符号粗细对齐旁边的标签，不用发丝线。固定符号略微上移，避免视觉上偏低。
- 材质是暖色半透明、顶边高光、细描边和软阴影。圆角 22。浮层最宽约 372。做不出折射时保持这个完成度，不要退回线框。
- 浅色和深色都要成立。选中文字用半透明蓝，字色不变。

## 没有锁定

- 缓存按什么判断相同，以及何时失效。
- 固定之后保留多久、关不关得掉。
- 语言如何判断，设置窗长什么样。
- Windows 上如何取得选中文字。图标使用 design/icon-source.png，托盘和窗口共用同一套字形。
- 预览里的 Inter 不是必须依赖。Windows 上用干净的无衬线字体即可，译文不要用粗黑体。

`popup.html` 里的点击只是为了查看状态，不代表这些交互已经定规。

## 2026-11-03 用户修订

- 上述缓存文字规则由本次要求替代：不显示缓存状态，右上角使用彩虹圆点关闭浮层，固定时也可关闭。
- 浮层与设置窗口的聚焦环共用绿色样式，包含帮助按钮、菜单、输入区和滚动区。
- 工具图标使用统一笔画，悬停、按压、固定、复制成功与翻译中均提供明确反馈。

## 2026-11-03 后续用户修订

- 问号是字段旁的简短提示，不画外圈。
- 关闭圆点改为单色，悬停不出现叉号；替代上面的彩虹要求。
- 聚焦环贴近控件边缘、收细，不使用粗大且外移的轮廓。
- 固定状态用图标填实区分，不加常驻绿色底衬。
- 浮层始终不占任务栏入口；未配置模型时，划词不自动打开设置页。

## 后续界面都要遵守

- 不把大段说明放在界面上。需要说明时，用问号按钮，悬浮或聚焦后显示。
- 常用请求字段保留，但默认不启用。设置页底部实时显示将要发送的请求代码；未启用或无效的字段不会出现。

## 2026-11-03 字体与配色复核

- 按用户本次整体配色审查要求，绿色聚焦环调整为暖琥珀色，浅色 `#9a713b`、深色 `#d0ae7c`，共用到全部窗口与菜单。启用开关和复制成功使用柔和绿色表达状态。
- 主界面品牌使用 Segoe Script 连笔字标，图标 28px；标题栏保持 56px，滚动层次使用渐隐阴影。
- 全应用共用无衬线界面字体栈。实际 Windows WebView 确认中文使用 Microsoft YaHei UI，标签 15px/600；正文和输入值保持常规字重。
- 主界面与弹窗的下拉选项共用 14px/600、30px 行高、12px 圆角，以及同一组悬停、选中、焦点、按压和阴影样式。
- 思考强度可直接输入或选择预设，左箭头、右对齐；关闭或空值不进入请求。
- 本次后续逐项修改与原生验证见 `../ui-followup-20261103/tasks.json`。

- 半透明浮层按相反亮度桌面复核：浅色不透明度 0.94→0.90，深色 0.94→0.92；小字使用适配玻璃表面的暖灰色，避免底下桌面使原文、模型和占位文字变淡。

- 翻译工具图标常态使用与辅助文字协调的暖灰，统一 1.5 单位笔画与简洁轮廓；固定仍用填实状态，复制成功仍用状态色。按压仅使用底色反馈，保持图形尺寸稳定。
